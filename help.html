Understanding Memory Functions (MC, MR, M+, M−, MS)

MS (Memory Store) Stores the current result into the memory register. An [M] indicator badge appears on screen.
MR (Memory Recall) Inserts the currently stored memory number into your active formula.
M+ (Memory Add) Adds the current on-screen number to the existing value stored in memory.
M− (Memory Subtract) Subtracts the current on-screen number from the value in memory.
MC (Memory Clear) Clears the memory register back to zero. The [M] indicator is removed.

Calculation History & Privacy

Every successful equation is saved locally to your device using the browser's standard localStorage API up to a maximum of 50 recent calculations.

  • Reusing results: Tap or click any history item to append its numeric result into your active equation.
  • Copy individual results: Tap the copy icon next to any history entry to copy just that result.
  • Clearing history: Click the "Clear History" button to open the confirmation dialog. Once cleared, all local records are permanently wiped.

Common Errors & Mathematical Limitations

“Cannot divide by zero” (শূন্য দিয়ে ভাগ সম্ভব নয়)

In standard arithmetic, division by zero is mathematically undefined. If you attempt 20 ÷ 0, the engine protects against NaN or Infinity and displays a clear message.

“Invalid mathematical expression”

Occurs if operators are misplaced (e.g. 5 + * 2) or if parentheses are not balanced (e.g. (10 + 5 without a closing bracket).

Floating-Point Arithmetic Strategy

Standard computing hardware uses IEEE 754 binary floating-point representation, which can cause micro-rounding quirks (such as 0.1 + 0.2 = 0.30000000000000004). NexVora QuickCalc includes a clean precision normalizer (cleanFloat) that eliminates epsilon noise while retaining up to 14 significant digits of exact precision.
